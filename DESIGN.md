# Minimi: remember the claim, then check the world

The hard part of this challenge is temporal grounding: identifying **what we said, when we said it, and what the evidence supports now**. Search alone cannot recover a user's shortlist. Conversation memory alone cannot establish today's prices. The architecture makes those two evidence types explicit.

**One request, one orchestrator, one tool.** A Next.js route validates the message and browser session, acquires a conversation run lease, and saves the user turn before inference. The server supplies the real clock, IANA timezone, calendar-date interpretations, recent dialogue, and relevant saved exchanges. The AI SDK calls an OpenRouter model through `generateText` with a Zod-backed `web_search` tool, backed by Exa. SDK model messages preserve provider reasoning metadata between private research rounds. Independent searches overlap through three workers. A hard limit of three research rounds, twelve searches, and a 170-second deadline prevents open-ended loops. The final `streamText` call has no tools; only text deltas and token usage are forwarded over the application SSE protocol. The SDK handles model transport and stream parsing; the server checks completion reasons so dropped or truncated streams cannot be saved as complete. Failures preserve useful evidence and produce an honest partial answer. Small provider adapters are injectable; the explicit bounded loop owns tool execution, validation errors, concurrency, and evidence tracking.

**Memory is evidence, not a summary pretending to be history.** Built-in SQLite stores exact user/assistant text, UTC timestamps, run status, query traces, and retrieved source passages with separate publication/retrieval dates. Recall prioritizes exact local-day windows, then FTS5 BM25 matches, then recent exchanges across the same owner's conversations. A compact question catalogue helps interpret vague references; it is explicitly not an old answer. Context is bounded, with truncation disclosed to the model. DST uses calendar boundaries, not subtraction of 24 hours. Missing or ambiguous history must lead to clarification. A saved answer proves what was said, not that it was true.

**Freshness is a comparison, not a search filter.** The research policy recovers the original entities and constraints first, checks current primary pricing pages without date filters, then seeks dated announcements separately. It distinguishes a confirmed change, a current value matching the saved answer, an incorrect old answer, and an unverified change date. No results cannot establish “nothing changed.” Citation IDs are assigned by the server and resolve to actual retrieved URLs; unknown IDs render as unverified. Web passages and old messages are treated as untrusted data. This reduces prompt-injection exposure but is not a claim of perfect model compliance or citation entailment.

**Voice is presentation, never another agent.** ElevenLabs Scribe uses short-lived single-use tokens for live transcription. Completed final-answer sentences feed an independent PCM stream player, which starts playback before synthesis completes. OpenRouter reasoning fields and research prose never enter the browser answer channel. A second filter removes reasoning tags; speech strips citations, URLs, Markdown, and fenced code. Cancellation stops scheduled audio and upstream requests. Turn-taking avoids self-transcription; explicit interruption resumes listening. Optional voice failure does not break text chat.

**Deliberate tradeoffs.** I rejected a multi-agent research swarm, a vector database, lossy rolling summaries as canonical memory, and open-ended orchestration: each adds latency or failure modes before this small corpus needs it. SQLite plus exact date recall is inspectable and cheap. FTS can miss semantic paraphrases and the catalogue is bounded; it is a baseline, not solved lifelong memory. Separating private research from public synthesis costs a model call but creates a testable voice boundary; a closed set of simple greetings/thanks skips planning for immediate streaming. Search-only access cannot prove every historical price or read arbitrary authenticated pages. Session cookies isolate local evaluation history, but public multi-user deployment needs real authentication and shared abuse controls.

**Evaluation and another week.** Deterministic tests cover date/DST recall, cross-chat retrieval, isolation/deletion, concurrency, tool budgets, parallel partial failure, fragmented SSE, cancellation, and speech leakage. An opt-in live harness seeds dated conversations and records actual answers, evidence, and latency; factual quality still needs human review. With another week I would build a frozen temporal benchmark with adversarial pages and conflicting price histories, score citation entailment and entity coverage, measure p50/p95 latency and cost, then add hybrid semantic recall and evidence-aware context compression only where measured failures justify them. I would also add authenticated accounts and resumable streams before public hosting.
